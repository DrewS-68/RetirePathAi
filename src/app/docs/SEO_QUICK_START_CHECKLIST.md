Competition Level

Create Blog Outline:

Audience: Australians aged 65-80 considering retirement villages
Word count: 2,000 words
Include: Introduction, 5-7 main sections, FAQ, conclusion
Make it SEO-optimized and helpful.

Write Blog Post:
Write a 2,000-word blog post based on this outline:
[PASTE OUTLINE]

Requirements:
- Conversational, helpful tone
- Australian English spelling
- Include statistics and examples
- Add internal link opportunities (mark as [LINK: text])
- Include call-to-action at end
- Optimize for featured snippets

Generate Village Page Content (Batch):
Generate SEO-optimized content for 50 retirement villages.

Create Meta Descriptions:
Write 5 variations of meta descriptions (155 chars max) for:
